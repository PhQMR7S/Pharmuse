## 1. المنفذ فعلياً

- استبدال قفل التسلسل في المسار النشط بتوصية Guided Path، وإتاحة Free Exploration. بقيت صلاحية الوصول والمراجعة العلمية مستقلتين عن ترتيب الدروس.
- نموذج جلسة بإصدار ثابت، وحفظ محلي واستئناف بعد إعادة التحميل، وتبديل عربي/إنجليزي دون فقد الإجابات أو الموضع.
- درس متداخل من 9 خطوات: تمهيد، شرح، تحقق، آلية، تطبيق، اختبار نهائي، وملخص ومصطلحات. دعم اختيار، مطابقة، ترتيب، ومخطط قابل للاختيار.
- شرح Simple / Detailed / Clinical وتكيف من سجل عدة إجابات. نافذة آخر 6 إجابات بحد أدنى 4 قرار هندسي موثق، وليست قاعدة علمية معتمدة.
- تصحيح فوري للتدريب، وتأجيل تلميحات وتصحيح الاختبار النهائي حتى الإرسال. منع الرجوع من اختبار غير مرسل للحصول على التلميحات.
- فصل Access / Completion / Mastery. Proficient عند 70%، وMastered عند 85% مع مراجعتين متأخرتين ناجحتين. الاختبار الحالي قصير؛ دقة النسبة مرتبطة بعدد أسئلته.
- مكافأة XP مرة واحدة لكل درس مؤهل، وعدم احتساب إعادة الطلب أو إعادة الدرس مكافأة جديدة. المراجعة المبكرة لا تمنح رصيد احتفاظ ولا تؤخر موعد مراجعة مستحقة.
- احتساب الهدف اليومي بعد إكمال الدرس، لا بمجرد إرسال الامتحان، والاحتفاظ بأثر الأداء على مستوى السؤال.
- بوابة نشر تتطلب اعتماد الدرس والأسئلة والمصادر؛ تغيير الحالة النصية وحده غير كافٍ. بوابة V1.2 تتطلب اجتياز جميع شروط V1.1.
- تحويل ثلاثة دروس تأسيسية إلى 27 خطوة و21 سؤالاً فريداً ثنائي اللغة، مع تفسير ومراجع. **جميعها مسودات؛ ليست منهج الفارما الكامل ولا محتوى منشوراً معتمداً.**
- الحفاظ على الأصول والشخصية والهوية والإصلاحات السابقة. مخطط SQL عدل محلياً لإزالة قفل المتطلبات السابقة، لكنه لم يطبق على أي قاعدة بيانات.

## 2. المختبر

| الفحص | النتيجة والدليل |
|---|---|
| الاختبارات الأصلية | الاحتفاظ بالاختبارات العشرة دون حذف؛ اختبار القفل القديم يخص توافق النظام السابق، لا المسار النشط |
| اختبارات الوحدة والسلوك والصلاحيات | 31 ناجحة، صفر فشل |
| TypeScript والبناء | ناجحان في تشغيل CI للنسخة أعلاه |
| المتصفح | 8 ناجحة: 4 سيناريوهات على الكمبيوتر ومحاكاة الهاتف |
| الاستكشاف الحر | فتح الدرس الثالث قبل إكمال الأول |
| الحفظ واللغة | حفظ الإجابة والموضع بعد العربية وإعادة التحميل، وحفظ المطابقة الجزئية |
| دورة درس كاملة | شرح وتحقق واختبار مؤجل التصحيح ونتيجة وإكمال وXP وهدف يومي |
| الصفحة والأصول | محتوى فعلي وصور محملة ولا أخطاء runtime في السيناريوهات المختبرة ولا تجاوز أفقي |

المراجعة البصرية تمت في Chrome: سطح مكتب نحو 1348×928، وإطارات فعلية بعرض 390 و768 ضمن مسار QA خاص بالمعاينة، إضافة لاختبارات Chromium بحجم 1440×1000 و390×844. تمت مراجعة ترتيب البطاقات، التنقل السفلي، وضوح الإجابات والتصحيح، والعربية RTL. قياس شاشة السؤال العربية: عرض المحتوى 373 وعرض التمرير 373، بلا تجاوز أفقي. لقطات المعاينة محفوظة مع التسليم. لقطة الهاتف تخص c82fcfa السابقة؛ التغيير اللاحق اقتصر على احتساب الهدف وأثر الأداء واختبارهما، ولقطة الكمبيوتر تخص النسخة النهائية أعلاه.

هذه محاكاة ومراجعة متصفح، وليست اختبار أجهزة iPhone فعلية أو Safari. المراجعة البصرية الفنية تمت؛ اعتماد صاحبة المشروع النهائي للتصميم لم يفترض تلقائياً. لا توجد حركة ثلاثية الأبعاد حقيقية مزعومة.

## 3. الناقص قبل قبول V1.1

- تغطية منهج Pharmacology وGeneral/Clinical Pharmacology والحقن والتداخلات كاملاً بمحتوى أصلي مرتبط بالفهرسة العلمية. الدروس الثلاثة لا تحقق ذلك.
- مراجعة علمية مستقلة لكل سؤال وشرح ومصدر وإذن استخدام قبل النشر. فحص الروابط أو وجود مرجع ليس بديلاً للمراجعة.
- جلسات ودرجات ومواعيد مراجعة ومكافآت محسوبة على الخادم؛ البيانات المحلية قابلة للتعديل وساعة الجهاز غير موثوقة. لا يجوز اعتبار منع التكرار المحلي حماية خادمية.
- ربط الحساب الحقيقي والمزامنة بين جهازين، واستكمال إدارة المحتوى على الخادم، واختبارات RLS والعزل والتزامن واستعادة الجلسة والبريد الفعلي.
- استكمال اختبار الأجهزة والمتصفحات الإضافية وإتاحة الوصول الشاملة؛ لا ندعي نجاح ما لم يختبر.

## 4. المحظور بسبب إعدادات خارجية

العائق المسجل: حد المشاريع المجانية النشطة في حساب Supabase، مع طلب قاعدة مستقلة لـPharmuse. لم ينشأ مشروع جديد ولم يعدل أو يوقف أو يحذف أي مشروع Supabase آخر في هذه المرحلة، ولم تطبق أي migration.

المسار الآمن موثق في [V11-SAFE-BACKEND-HANDOFF-AR.md](V11-SAFE-BACKEND-HANDOFF-AR.md): توفير مشروع معزول مجاني متاح للحساب المخصص، ربط متغيرات Preview فقط، ثم إعداد migrations لمحرك V1.1 واختبارها. مخطط SQL القديم ليس migration نهائية جاهزة لهذا المحرك. لا تنقل مفاتيح أو جداول من مشاريع أخرى ولا ترسل service-role للمتصفح.

تعذر تنزيل Chromium محلياً بسبب ملف تنزيل فارغ؛ تم تشغيل اختبارات المتصفح بنجاح في GitHub Actions، إضافة إلى المراجعة البصرية في المتصفح المتصل. ليس ذلك عائقاً مفتوحاً لاختبارات CI.
