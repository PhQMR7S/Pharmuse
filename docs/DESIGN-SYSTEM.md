# Pharmuse design system

Reference: supplied Pharmuse multi-screen visual board and original QMR7S blue-orange capsule.

- Lavender canvas #f7f4fd, plum text #291442, purple #8245d9, pale pink/blue/peach subject surfaces.
- Nunito English / Rubik Arabic with system fallbacks. 12–15px body, 30–60px major headings depending on device.
- 228px desktop sidebar; separate 70px mobile bottom navigation plus drawer. RTL uses logical spacing.
- 14px action corners, 21–25px panels, restrained inset highlights, shallow 3px action depth.
- Unified Lucide outlined icons. No emoji substitutes.
- Character source retained unchanged as qmr7s-original.png. Transparent derivative extracted with image generation. Preserves headset, glasses, microphone, gloves, sneakers, backpack, and QMR7S mark.
- Eight semantic mascot states use the same character, local two-dimensional transforms, and contextual speech. These are not real-time 3D animations or eight newly rendered poses.
- Reduced motion respects system preferences and an explicit user setting.
- Development and editorial approval status stays visible; no fabricated users, streaks or leaderboard.

Generated concept uses the same sidebar, hero, zero-state widgets, two-column learning/goal section and four subject tiles. Intentional implementation changes: no fake notifications, no fake leaderboards, guest rather than invented identity, daily goal changes actual local state, profile/admin services clearly unavailable until configured.
